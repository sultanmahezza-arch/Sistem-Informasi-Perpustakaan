# Dokumentasi Sistem Informasi Perpustakaan (SIPUS) Berbasis Cloud

## 📖 Deskripsi Proyek
Repository ini dibuat sebagai media penyimpanan dokumentasi untuk **Sistem Informasi Perpustakaan (SIPUS) berbasis cloud**. Sistem ini dibangun dengan tujuan utama untuk:
- Mengelola koleksi buku cetak dan digital secara terpusat.
- Mempercepat proses peminjaman, pengembalian, dan perpanjangan buku.
- Memudahkan pencarian koleksi melalui katalog online.
- Mengurangi kesalahan pencatatan dan risiko kehilangan buku.

Proyek dokumentasi ini disusun untuk memenuhi tugas mata kuliah di program studi Teknologi Rekayasa Perangkat Lunak.

## 👥 Pengguna Sistem
Sistem ini dirancang untuk mendukung aktivitas berbagai pihak di perpustakaan, antara lain:
* **Anggota:** Mencari katalog, meminjam, dan membaca koleksi digital.
* **Pustakawan:** Mengelola koleksi dan menangani layanan sirkulasi.
* **Pimpinan:** Memantau laporan dan statistik operasional perpustakaan.
* **Administrator:** Mengatur hak akses dan menjaga keamanan sistem.

## 📊 Jenis Informasi yang Dikelola
SIPUS dirancang untuk mengelola berbagai data krusial, meliputi:
* **Data Koleksi:** Judul, pengarang, ISBN, kategori, dan jumlah eksemplar.
* **Data Anggota:** Informasi profil pengguna yang terdaftar.
* **Data Transaksi:** Pencatatan sirkulasi mulai dari peminjaman, pengembalian, hingga denda.
* **Koleksi Digital:** Berkas elektronik seperti *e-book*, jurnal, dan skripsi.
* **Laporan & Statistik:** Rekapitulasi aktivitas perpustakaan untuk bahan evaluasi pimpinan.

## ☁️ Implementasi Cloud Computing
Penggunaan teknologi *cloud* pada SIPUS sangat dibutuhkan dan memberikan banyak manfaat dibandingkan penggunaan komputer lokal (on-premise), di antaranya:
1. **Aksesibilitas Tinggi:** Sistem dan penyimpanan file digital yang besar dapat diakses 24 jam dari mana saja, tidak terbatas di satu komputer.
2. **Skalabilitas Mudah:** Kapasitas server dan penyimpanan dapat ditambah dengan mudah ketika jumlah pengguna semakin meningkat.
3. **Keamanan & Keandalan:** Data anggota dan koleksi lebih aman karena sistem cloud menyediakan fitur *backup* dan replikasi otomatis untuk mencegah data hilang.
4. **Efisiensi Biaya & Pembaruan:** Biaya operasional lebih hemat karena menggunakan skema bayar sesuai pemakaian (pay-as-you-go). Selain itu, pembaruan sistem berjalan secara otomatis dan terpusat.
